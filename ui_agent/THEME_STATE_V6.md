They are not marked corrupt for missing/incompatible policy. configureThemePolicy validates current/history/pending theme values before changing the policy, then restores pending values without navigating. Ordinary resume failure restores previous theme/layout/policy; original raw saved record remains retained. Structurally invalid saved data follows the prior corruption path and blocks save. Actual Qt Settings disk/OS failures and crash atomicity are unverified.
